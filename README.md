# Java Training Phase I - Course Repository

This repository contains a collection of Java programs developed during Phase I of the Java training. The programs cover fundamental concepts including basic input/output, mathematical operations, conditional logic, loops, pattern printing, and array manipulations (1D and 2D).

## Day 1: Basics and Formatting

Focuses on initial setup, standard input/output, and formatting techniques.

  * **Precision and Width**: Handling zero-padding and field widths in output.
  * **Math Functions**: Utilizing `Math.floor`, `Math.ceil`, `Math.sqrt`, and `Math.pow`.
  * **ATM Machine**: A logic-based program to calculate the number of currency notes for a given amount.
  * **Basic String Operations**: Reading and splitting input strings.

## Day 2: Conditional Statements

Covers decision-making structures like `if-else` and `switch`.

  * **Triangle Classification**: Determining if a triangle is Equilateral, Isosceles, or Scalene.
  * **Leap Year Checker**: Implementing nested logic to identify leap years.
  * **Electricity Bill Calculator**: Multi-tiered pricing logic based on consumption.
  * **Simple Calculator**: A switch-case based arithmetic calculator.
  * **Ticket & Bus Fare Calculators**: Complex conditionals involving age, day of the week, and travel routes.

## Day 3: Pattern Printing

A series of programs using nested loops to print various shapes and characters.

  * **Geometric Shapes**: Square, Right Triangle, Inverted Right Triangle, and Hallow Square.
  * **Alphabet Patterns**: Character patterns for 'I', 'E', 'U', 'Z', 'X', 'A', 'S', and 'M'.
  * **Advanced Patterns**: Pyramid, Left Triangle, Swastika, and curved variations of 'S' and 'O'.

## Day 4: Mathematical and Digit Operations

Programs designed to manipulate individual digits within numbers.

  * **Digit Counting**: Count total digits or occurrences of a specific digit.
  * **Number Properties**: Programs to check for Palindrome, Armstrong, Adam, and Strong numbers.
  * **Prime Digits**: Identifying and printing only the prime digits from a number.
  * **Reversal**: Reversing numbers and printing digits from right to left.

## Day 5: 1D Array Operations

Introduction to data structures through one-dimensional arrays.

  * **Traversing and Reversal**: Basic array iteration and printing in reverse.
  * **Statistics**: Finding the sum, largest element, and smallest element.
  * **Counting**: Counting even/odd numbers and occurrences of 0s/1s.
  * **Search & Compare**: Searching for elements (Find Home Address) and comparing two arrays for equality.
  * **Advanced Logic**: Maximum product of two elements and Shuffling arrays.

## Day 6: 2D Array (Matrix) Operations

Handling multi-dimensional data structures.

  * **Matrix Basics**: Accepting and displaying 2D arrays in matrix format.
  * **Equality**: Checking if two matrices are identical using `Arrays.deepEquals`.
  * **Summations**: Calculating the sum of all elements, specific rows, specific columns, and diagonal elements (Major and Minor).
  * **Search and Analysis**: Searching for elements and identifying the row with the maximum number of zeros.
  * **Triangular Matrices**: Calculating the sum of the upper triangular part of a matrix.
